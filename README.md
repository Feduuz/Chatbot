# 🤖 Chatbot Financiero – Proyecto Final

Este proyecto consiste en el desarrollo de un **Chatbot Financiero Inteligente**, diseñado para brindar información financiera exacta, actualizada y contextualizada de forma conversacional.
El chatbot permite consultar datos como inflación, dólar, acciones, criptomonedas, plazos fijos y riesgo país, combinando respuestas estructuradas con razonamiento mediante modelos de lenguaje (LLM).
Forma parte del proyecto final de carrera, con un enfoque técnico, escalable y orientado a producción.

---

## 🎯 Objetivo del proyecto

El objetivo principal es facilitar el acceso a información financiera confiable, permitiendo que el usuario:
  Realice consultas en lenguaje natural
  Obtenga respuestas directas mediante botones interactivos
  Reciba explicaciones detalladas cuando la pregunta lo requiera
  Mantenga el contexto de la conversación
  El sistema diferencia automáticamente entre:
  Comandos directos (menú / botones)
  Preguntas complejas, que requieren razonamiento sobre datos reales

## ▶️ Ejecutar el proyecto en local
```bash
# Clonar el repositorio
git clone https://github.com/Feduuz/Chatbot

# Entrar al proyecto
cd chatbot

# Crear entorno virtual (opcional pero recomendado)
python -m venv venv
source venv/bin/activate  # Linux / Mac
venv\Scripts\activate     # Windows

# Instalar dependencias
pip install -r requirements.txt

# Ejecutar el servidor
python app.py
```
